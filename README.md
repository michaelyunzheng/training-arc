# Training Arc

A focused plan to become a better programmer and get sharp for technical interviews.

## Core

**DSA + C++**  
NeetCode 150. Learn the patterns properly and revisit problems until I can explain the solution clearly.

**Engineering**  
MIT Missing Semester. Shell, Git, debugging, profiling and development workflow.

**Build**  
Ship a real-time multiplayer game. Use it to get better at architecture, networking, databases, concurrency, testing and failure handling.

## Systems

- OSTEP — processes, memory, threads, locks, concurrency
- Beej — sockets, TCP/IP, client/server fundamentals
- PostgreSQL — schemas, indexes, transactions, query plans
- System Design Primer — caching, queues, replication, consistency, scaling

## Practice

One timed mock interview every week.

Keep building. Keep getting better.
