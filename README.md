# Training Arc

A focused plan to become a better programmer and get sharp for technical interviews.

## Core

**[DSA + C++ — NeetCode 150](https://neetcode.io/)**
Learn the patterns properly and revisit problems until I can explain the solution clearly.

**[Engineering — MIT Missing Semester](https://missing.csail.mit.edu/)**
Shell, Git, debugging, profiling and development workflow.

**Build**
Ship a real-time multiplayer game. Use it to get better at architecture, networking, databases, concurrency, testing, observability and failure handling.

## Systems

* [OSTEP](https://pages.cs.wisc.edu/~remzi/OSTEP/) — processes, memory, threads, locks, concurrency
* [Beej's Guide to Network Programming](https://beej.us/guide/bgnet/) — sockets, TCP/IP, client/server fundamentals
* [PostgreSQL Documentation](https://www.postgresql.org/docs/current/tutorial.html) — schemas, indexes, transactions, query plans
* [System Design Primer](https://github.com/donnemartin/system-design-primer) — caching, queues, replication, consistency, scaling

## Practice

One timed mock interview every week. Mix coding, project deep dives and system design as interviews get closer.

Keep building. Keep getting better.
